## API Notes

- Use station names or aliases in the `origin` and `destination` fields when `inputType` is `station`.
- The exit values shown here are the zero-based values for the `exit` field used by the train-car endpoint.
- Empty arrays in the exit-map columns mean there is no recommended car-group for that station, direction, and exit combination.
