## Acceptable Use

The API is provided for reasonable use related to its intended purpose.

Please do not use the API to:

* Send excessive or abusive traffic
* Attempt to overload, disrupt, or damage the service
* Bypass rate limits or other access restrictions
* Probe or attempt to exploit vulnerabilities
* Gain unauthorized access to the API or its systems
* Send malicious or harmful requests

To protect the service and other users, requests may be rate-limited, restricted, or blocked when necessary.

The API may temporarily or permanently restrict access from clients that generate excessive traffic or otherwise abuse the service.

Limited request information, including the optional `sender` value and technical request information, may be retained for abuse prevention, monitoring, and service reliability. This information is not publicly disclosed.

If your application makes repeated requests, use reasonable request rates and cache results where practical.

## Service Availability

The API is provided as a public service and is not guaranteed to be available at all times.

The API may be temporarily limited, modified, or unavailable due to maintenance, updates, unexpected traffic, security concerns, or other operational reasons.

If you are building an application that depends on the API, please implement reasonable error handling and avoid assuming that every request will succeed.
